# 小程序端功能规划 PRD v1.0

## 1. 产品定位

小程序端不是 Web 后台的完整复制，而是「移动轻量入口」。

核心目标：

1. 让用户随时随地使用 AI。
2. 让企业员工随时查询知识库。
3. 让客户通过小程序体验 Agent 和提交线索。
4. 让代理商/运营人员方便展示产品、查看客户和收益。
5. 作为企业 AI SaaS 的移动端获客入口。

---

## 2. 用户角色

### 普通用户

- 使用 AI 对话
- 查看作品
- 使用知识库问答
- 使用 Agent
- 查看 Token 余额
- 购买套餐

### 企业员工

- 使用企业知识库
- 调用企业 Agent
- 查看企业公告
- 提交反馈
- 移动审批轻流程

### 企业管理员

小程序端只提供轻量能力：

- 查看企业使用情况
- 查看成员数量
- 查看知识库状态
- 查看消耗数据
- 查看线索

复杂管理仍放在 Web 后台。

### 代理商 / 合伙人

- 查看推广二维码
- 查看客户列表
- 查看订单
- 查看分润
- 查看素材
- 分享产品海报

---

## 3. 功能模块

### 3.1 首页

首页目标：快速进入核心能力。

页面元素：

- 顶部品牌区域：先知AI
- 快捷入口：
  - AI 对话
  - 知识库问答
  - 我的 Agent
  - AI 绘图
  - AI 视频
  - PPT 生成
  - 作品中心
- 套餐/余额卡片
- 最近使用
- 企业公告
- 推荐 Agent

### 3.2 AI 对话

功能：

- 文本对话
- 多模型选择
- 历史会话
- 收藏会话
- 结果复制
- 结果分享

MVP 范围：

- 文本输入
- 流式回复
- 历史记录
- 模型选择
- Token 消耗展示

### 3.3 企业知识库问答

功能：

- 选择知识库
- 提问
- AI 回答
- 引用原文
- 查看来源文件
- 收藏答案
- 分享答案

MVP 范围：

- 单知识库问答
- 显示引用来源
- 支持最近提问记录

### 3.4 Agent 助手

功能：

- 企业预设 Agent
- 个人常用 Agent
- Agent 分类
- Agent 对话
- Agent 分享
- Agent 留资表单

典型 Agent：

- 销售助手
- 客服助手
- 招聘助手
- 文案助手
- 合同助手
- 企业知识库助手

### 3.5 作品中心

功能：

- 查看 AI 绘图作品
- 查看 AI 视频作品
- 查看 PPT 文档
- 下载/分享
- 收藏
- 删除

小程序端以查看和分享为主，复杂编辑放 Web 端。

### 3.6 会员与 Token

功能：

- 查看余额
- 查看消耗记录
- 查看套餐
- 购买套餐
- 充值
- 开票入口（后期）

MVP：

- 余额展示
- 消耗记录
- 套餐列表
- 微信支付

### 3.7 消息通知

功能：

- 任务完成通知
- 系统公告
- 套餐到期提醒
- Token 不足提醒
- 企业通知
- Agent 留资通知

### 3.8 客户线索收集

这是小程序端很重要的商业功能。

功能：

- 企业介绍页
- 产品介绍页
- Agent 体验入口
- 留资表单
- 联系电话
- 微信客服
- 销售线索后台同步

字段：

- 姓名
- 手机号
- 公司名称
- 需求描述
- 来源渠道
- 推荐人/代理商ID

### 3.9 代理商中心

功能：

- 我的推广码
- 我的客户
- 我的订单
- 我的收益
- 推广素材
- 邀请记录
- 提现记录（后期）

注意：代理商功能必须合规，避免多级分销风险。

### 3.10 我的

功能：

- 个人资料
- 企业身份
- 当前套餐
- Token余额
- 订单记录
- 发票信息
- 联系客服
- 设置

---

## 4. 页面结构

建议小程序底部 Tab：

1. 首页
2. AI
3. 知识库
4. 作品
5. 我的

代理商入口放在“我的”中，不单独占底部 Tab。

---

## 5. 小程序与 Web 端关系

Web 端：

- 完整后台
- 企业管理
- 知识库管理
- Agent 配置
- Workflow 编排
- 计费管理
- 系统配置

小程序端：

- 移动使用
- 轻量查看
- 分享获客
- 消息通知
- 快速体验

原则：小程序不要做成复杂后台。

---

## 6. 技术建议

推荐：

- uni-app / Taro 二选一
- TypeScript
- Pinia 状态管理
- 统一调用后端 REST API
- 微信登录
- 微信支付
- 订阅消息

如果当前主项目是 Vue3，优先建议小程序用 uni-app，学习和复用成本更低。

## 8. MVP 优先级

第一期必须做：

1. 微信登录
2. 首页
3. AI 对话
4. 企业知识库问答
5. 我的
6. Token 余额
7. 作品中心
8. 客户线索表单

第二期再做：

1. Agent 助手
2. 微信支付
3. 消息通知
4. 代理商中心
5. 分享海报

第三期再做：

1. AI 绘图
2. AI 视频
3. PPT 生成
4. 轻量审批
5. 企业数据看板

---

## 9. 验收标准

小程序一期上线标准：

- 用户可微信登录
- 可正常发起 AI 对话
- 可查看历史会话
- 可使用企业知识库问答
- AI 回答可显示引用来源
- 可查看 Token 余额
- 可查看作品
- 可提交客户线索
- 页面适配主流手机
- 支付/消耗/权限不出错
- 后端日志可追踪

---

## 10. 开发原则

小程序端必须坚持：

- 轻量
- 快速
- 易分享
- 不复杂
- 不替代 Web 后台
- 重点服务移动使用和获客
