# 小程序 UI 设计规范

## 设计定位

企业级、轻量、清爽、科技感。

## 色彩建议

- 主色：蓝紫色
- 强调色：亮橙色
- 背景：浅灰白
- 卡片：白色
- 文字：深灰

## 页面风格

- 首页采用功能宫格 + 余额卡片 + 最近使用
- AI 对话页面保持简洁
- 知识库问答突出引用来源
- 我的页面突出身份、套餐、余额
- 线索表单要简单，减少填写压力

## 组件规范

所有页面必须组件化：

- Header
- Card
- Button
- Input
- ChatBubble
- FeatureGrid
- ListItem
- EmptyState

## 交互原则

- 输入路径短
- 分享路径明显
- 不做复杂后台操作
- 重要按钮固定底部
- AI生成任务要有状态反馈
