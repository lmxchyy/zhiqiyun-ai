# 首页创作灵感与模板中心实施报告

## 1. 实施结论

本次在现有首页、认证、模型中心、生成任务、积分扣费、作品中心、媒体中心和后台 RBAC 之上完成扩展，没有另建生成链路或用户体系。

完整链路已接通：精选案例 -> 灵感广场 -> 模板详情 -> 复制/收藏 -> 生成同款 -> 恢复模型与参数 -> 复用原生成任务 -> 成功后进入作品中心并记录统计。

## 2. 复用模块

- 小程序共享 API Client、登录保护和登录后动作恢复。
- `generation-tasks` 生图/视频任务、积分预扣/退款、任务轮询和作品资产创建。
- PPT 大纲、生成、轮询、导出和作品历史。
- 模型中心的模块模型与启停状态，已下架模型自动解析兼容模型。
- 媒体中心上传与 Storage，开发环境 MinIO，生产环境沿用现有 S3/R2/OSS/COS 兼容配置。
- 后台管理路由、角色权限和操作人上下文。

## 3. 数据库变更

迁移：`database/migrations/065-inspiration-template-center.sql`

新增表：

- `inspiration_categories`
- `inspiration_templates`
- `inspiration_favorites`
- `inspiration_events`
- `inspiration_template_versions`

增加公开列表、租户分类、事件统计和用户收藏索引；增加内容查看、管理、审核、发布四类权限。迁移可重复执行，开发库已执行，写入 7 个分类、6 个精选模板和 16 条角色权限。

## 4. 接口清单

| 场景 | 方法与路径 | 鉴权 |
| --- | --- | --- |
| 分类 | `GET /api/v1/inspirations/categories` | 游客可用 |
| 首页精选/换一换 | `GET /api/v1/inspirations/featured` | 游客可用 |
| 灵感广场分页 | `GET /api/v1/inspirations` | 游客可用 |
| 模板详情 | `GET /api/v1/inspirations/:id` | 游客可用 |
| 收藏/取消 | `PUT/DELETE /api/v1/inspirations/:id/favorite` | 登录 |
| 复制/使用/成功事件 | `POST /api/v1/inspirations/:id/events` | 除 view 外登录 |
| 后台列表/CRUD | `/api/v1/admin/inspirations...` | RBAC |
| 审核/发布/撤回 | `.../:id/audit/*`、`.../:id/publish`、`.../:id/withdraw` | 独立权限 |
| 排序/批量/统计 | `.../sort`、`.../batch`、`.../statistics` | RBAC |
| 版本/回滚 | `.../:id/versions`、`.../:id/rollback` | RBAC |

公开列表不返回完整提示词、负面提示词、生成参数和参考素材；详情接口才返回。公开查询校验发布、审核、上下线时间、展示平台、租户范围和软删除状态。

## 5. 小程序实现

- 首页保留现有结构，将静态创作灵感替换为真实精选接口，支持 7 个分类、换一换、查看更多、骨架屏、失败重试和双列卡片。
- 新增灵感广场：双列瀑布流、搜索、分类、分页、下拉刷新、上拉加载、空状态和错误状态。
- 新增详情：图片/视频预览、AI 生成标识、完整提示词、负面提示词、模型参数、复制、收藏和生成同款。
- 视频仅显示封面，详情由用户主动播放；图片使用缩略图、懒加载和失败占位。
- 路由只传 `templateId`，完整模板放入 30 分钟短时草稿；生图、视频和 PPT 页面重新读取并允许用户修改。
- 生图/视频恢复 prompt、negativePrompt、model、ratio/size、quality、duration、referenceAssets 和扩展参数。
- PPT 恢复主题、负面约束、页数、语言、场景、风格和配图开关。
- `generate_success` 只在任务轮询确认成功后写入，不把提交成功当成生成成功。

## 6. 后台管理

入口：`内容运营 -> 创作灵感管理`。

支持新增、编辑、复制、删除、素材上传、素材预览、图片/视频/PPT 类型、提示词、模型、JSON 参数、参考素材、平台、标签、适用租户、推荐/热门/置顶、排序、定时上下线、审核通过/驳回、发布、撤回、批量操作、统计、历史版本与回滚。用户作品转模板时必须显式确认素材发布授权。

## 7. 安全与性能

- 游客仅可浏览，复制、收藏和生成同款使用现有登录保护。
- 后台接口使用独立 view/manage/audit/publish 权限，批量动作按发布权限保护。
- 公开内容按租户、平台、审核、状态和有效期隔离。
- 首页单模块失败不会影响首页其他区域；分类缓存 10 分钟，精选结果缓存 2 分钟。
- 列表裁剪大字段，详情按需加载；数据库分页、索引、缩略图和视频封面均已接入。
- 私人作品不会自动公开；存在 `source_asset_id` 时必须确认 `source_authorized` 才可发布。

## 9. 上线与回滚

上线前执行 `065-inspiration-template-center.sql`，确认生产 Storage/CDN 公网域名、模型中心有效模型、内容运营角色权限和小程序 request/download 合法域名。生产模板素材应通过媒体中心上传并完成版权、隐私和内容审核。

代码回滚时回退本次功能文件和路由注册即可；数据库表为独立新增，不影响现有生成与作品数据，紧急回滚可保留表结构并停止入口，不建议直接删除已有运营数据。
