# 知启云AI渠道生态中心 V1.3.2 小比例真实切换实施说明

## 当前发布状态

- 代码具备 `LEGACY`、`SHADOW`、`CANARY`、`V132` 四种模式。
- 默认配置继续保持 `SHADOW`，`real_switch_enabled=false`。
- 本阶段不自动开启任何真实 V1.3.2 订单。
- 首阶段后台只允许账号、套餐和订单白名单，不开放全局百分比。

## 订单固化

- 首次履约前把 `settlement_engine` 写入不可变订单决策表。
- 同一订单的支付重试、人工补发、退款和重新履约读取原决策。
- rollout 配置回滚仅影响尚未产生决策的新订单。
- 已选择 V1.3.2 的订单永久使用当时的规则集 ID 和版本。

## 单写源

- 每个订单在真实写入前声明 `LEGACY` 或 `V132` 唯一写源。
- 同源重复声明幂等。
- 不同源声明立即失败并回滚事务。
- 两个引擎共用现有佣金记录、钱包投影、Token、身份和退款事务，不并行写两套真实余额。

## 白名单阶段

- 租户：每个租户独立 rollout 配置。
- 账号：`allow_user_ids`。
- 套餐：`allow_plan_ids`。
- 订单：`allow_order_ids`。
- 拒绝名单优先于允许名单。
- 全局比例开关在后台 API 中被拒绝。

## 后续比例阶段

- 白名单验收后才开放 `percentage_rollout_enabled`。
- 一致性哈希输入固定为 `tenant_id + order_id`，禁止随机数。
- 顺序为 1%、5%、20%、50%、100%。
- 每一级仅影响新订单，历史订单不重新判定。

## 回滚

- `CANARY -> SHADOW`：新订单回到 Legacy，历史 V1.3.2 订单不变。
- `SHADOW -> LEGACY`：关闭旁路计算，仅影响新订单。
- 已入账订单通过原引擎规则快照退款，禁止迁回另一引擎重算。
- 金额异常必须生成冲正流水，不直接改余额。

## 商业参数

- 业务计算只读取版本化套餐、佣金和推荐奖励规则。
- 996、5000、3000、2000、1000、400、300、200 等金额仅存在于默认初始化迁移和测试断言。
- 测试与生产必须分别创建、发布和绑定规则版本，禁止共享数据库配置。
