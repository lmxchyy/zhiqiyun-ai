## 二、已修复问题

| 序号 | 问题 | 修复结果 |
| --- | --- | --- |
| 1 | `custom-tab-bar` 已有源码但 `pages.json` 没有启用原生 `tabBar.custom`，真机 Tab 点击/选中状态不稳定 | 已在 `pages.json` 启用 4 个原生自定义 Tab：首页、创作、作品、我的 |
| 2 | 主 Tab 页面跳转存在使用普通页面跳转的风险 | 四个 Tab 页面统一走 `uni.switchTab`，失败时使用 `uni.reLaunch` 兜底 |
| 3 | 原生 custom-tab-bar 与页面内 V531 TabBar 可能重复或遮挡点击 | MP-WEIXIN 用户主 Tab 只保留原生 custom-tab-bar；非主 Tab/非小程序环境保留页面内 TabBar |
| 4 | 四个主页面未统一启用下拉刷新/触底加载配置 | 首页、创作、作品、我的均启用 `enablePullDownRefresh` 和 `onReachBottomDistance` |
| 5 | 作品页列表被前端截断，只显示前 4 条 | 移除固定截断，改为加载后端 `/api/v1/assets` 返回的完整列表 |
| 6 | 作品详情页能力不足，下载/复制/删除/分享没有完整真实链路 | 重建作品详情：真实读取资产列表、预览、复制链接、带 Token 下载、二次确认删除、分享 |
| 7 | PPT 生成页仍使用旧 `/api/ppt/*` 和本地 mock/history fallback | 改为 `/api/v1/ppt/*`，移除 mock 历史和假任务回退 |
| 8 | PPT 下载、删除、分享设置存在“预留/假成功” | 下载走 `/api/v1/ppt/export/pptx` 或真实文件 URL，删除走后端 DELETE，分享复制真实任务链接 |
| 9 | “我的-常用服务/权益”部分入口失败时只有 toast，难以确认接口状态 | 任务、帮助、企业认证、关于接口均纳入真实请求和弹窗反馈 |
| 10 | E2E 验证脚本在 Windows/uni-h5 下会误用旧 dev server、CORS 阻断请求、残留进程 | 增加强制启动当前源码、显式 API Base URL、小程序网络模拟、Windows 进程树清理 |

## 五、新增或修改后端接口

本轮没有新增后端接口，也没有新增数据库迁移。修复策略是让前端适配当前后台已经存在的 `/api/v1` 接口：

| 能力 | 使用接口 |
| --- | --- |
| 资产列表/下载/删除 | `GET /api/v1/assets`、`GET /api/v1/assets/:id/download`、`DELETE /api/v1/assets/:id` |
| 通用生成任务 | `GET/POST /api/v1/generation-tasks`、`GET /api/v1/generation-tasks/:id` |
| PPT 生成 | `GET /api/v1/ppt/models/text`、`GET /api/v1/ppt/models/image`、`POST /api/v1/ppt/generate`、`GET /api/v1/ppt/tasks/:id`、`POST /api/v1/ppt/export/pptx` |
| 用户/钱包/点数 | `/api/v1/member/profile`、`/api/v1/member/wallet`、`/api/v1/points/account` |
| 知识库/智能体 | `/api/v1/knowledge-agents`、`/api/v1/knowledge-conversations` |
| 页面配置/系统状态 | `/api/v1/app/page-config/profile`、`/api/v1/user/api-settings`、`/api/v1/health` |

数据库变更：无。

## 八、微信开发者工具人工验收步骤

1. 打开微信开发者工具，导入 `apps/user-uni/dist/build/mp-weixin`。
2. 确认后端 Docker 服务运行，接口地址与小程序环境一致；本机验证地址为 `http://127.0.0.1:3100`，真机需使用局域网可访问地址。
3. 清空小程序缓存后登录测试账号。
4. 依次点击底部 Tab：首页、创作、作品、我的，确认 selected 图标和文字同步。
5. 首页：点击快捷创作、通知、头像/我的入口、语音输入；语音输入应提示未接入识别服务。
6. 创作：逐个点击 AI 设计、AI 视频、PPT 生成、智能体、信息图、评审、模板卡片，Network 中应出现对应 `/api/v1` 请求。
7. 作品：测试搜索、筛选、类型 Tab、批量管理、作品卡片详情；详情页测试预览、复制、下载、删除二次确认和分享。
8. 我的：测试资料编辑、充值入口、任务记录、点数明细、订单、邀请推广、身份权限、设置、帮助客服、企业认证、关于。
9. 分别验证未登录/登录失效：清除 Token 后进入非首页功能，应回到登录或显示授权提示。
10. 下拉刷新：首页、创作、作品、我的均应触发刷新；作品页上拉加载不应空白或重复页面。
