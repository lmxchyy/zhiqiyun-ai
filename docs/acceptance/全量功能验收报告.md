## 3. 前后端接口映射表

创作生图主链路：

| 步骤 | 接口 | 作用 |
| --- | --- | --- |
| 登录 | `POST /api/v1/auth/login` | 获取访问令牌 |
| 模型配置 | `GET /api/v1/module-schema?module_code=image_generation&model_name=gpt-image-2` | 获取可用生图模型配置 |
| 创建任务 | `POST /api/v1/generation-tasks` | 创建 `TEXT_TO_IMAGE` 任务 |
| 查询任务 | `GET /api/v1/generation-tasks/:id` | 轮询任务状态和结果 |
| 作品列表 | `GET /api/v1/assets` | 查询入库作品 |
| 作品详情 | `GET /api/v1/assets/:id` | 查询独立作品详情 |
| 积分账户 | `GET /api/v1/points/account` | 校验扣点和流水 |

完整映射见 [前后端接口映射表.md](./前后端接口映射表.md)。

## 10. 剩余风险

- 外部模型、NewAPI、对象存储和 CDN 可用性不由本仓库单独保证，应保留超时、告警和降级监控。
- 微信开发者工具自动化不等于真机，授权、支付、相册、分享和下载必须做真机验收。
- 历史任务/资产的一致性问题需要单独的数据修复方案，不能通过前端兜底彻底解决。
- 当前工作区非常脏，提交时应只暂存本次确认过的文件，避免混入其他进行中的改动。

## iPhone 17 电商图复测步骤

1. 确认后端健康：访问 `http://127.0.0.1:3100/api/v1/health`。
2. 编译小程序：`npm.cmd run build:user-mp-weixin`。
3. 微信开发者工具导入 `apps/user-uni/dist/build/mp-weixin`。
4. 使用测试账号登录后进入“创作”。
5. 输入：`生成一张 iPhone 17 电商平台商品主图，1:1 方图，纯白到浅灰渐变背景，手机正面与背面组合陈列，突出旗舰影像、全天续航、轻薄机身，不要水印。`
6. 点击“立即生成”，应进入 `pages/user/UserImageCreationPage`，确认模型、尺寸和预计积分后提交。
7. 任务成功后在“作品”查看图片与详情，同时在积分记录确认本次扣点。

也可以直接运行真实接口冒烟测试：`node tools/smoke-generate-ecommerce-image.mjs`。该命令会登录、创建任务、轮询、核对作品与积分，并下载生成图片。
