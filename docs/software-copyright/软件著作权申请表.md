## 二、开发目的

本软件面向企业、团队和内容创作者，建设统一的人工智能创作、智能体协作、知识库问答与企业运营平台。系统将图像、视频、演示文稿、智能问答和知识检索等能力集中到同一账号与作品体系中，通过统一模型接入、任务管理、Token/算力计费、企业权限和内容安全机制，提高内容生产和组织协作效率。

## 三、主要功能

1. 支持手机号验证码、账号密码及微信相关登录方式，并提供会话管理与角色切换。
2. 支持 AI 智能对话、文生图、参考图生图、视频生成、PPT 大纲生成、页面编辑与导出。
3. 支持 AI 智能体、企业知识库、文档摄取、向量检索、引用展示和多轮对话。
4. 支持作品、文件、生成任务、收藏、下载、归档、恢复和再次创作。
5. 支持会员、钱包、Token/算力、订单、支付、退款、发票和权益发放。
6. 支持企业、组织、成员、角色、AI 员工、企业额度、认证和审计日志管理。
7. 支持管理端的用户、租户、模型、渠道、计费、权限、内容审核、Agent 和知识库管理。

## 四、技术特点

- 用户端以 Vue 3、TypeScript、uni-app 和 Vite 构建，同一代码基线覆盖 App、H5 和微信小程序。
- 管理端以 Vue 3、TypeScript、Pinia、Axios、Element Plus 和 Vite 构建。
- 服务端采用 Go 1.25 与 Gin，提供 REST 风格 API，并以模块化单体组织认证、生成、PPT、知识库、企业、支付和管理业务。
- 数据层实际采用 PostgreSQL（pgx 驱动），Redis 承担会话、缓存、队列和分布式锁等能力；媒体文件可接入 S3 兼容对象存储或本地存储。
- AI 调用通过统一模型提供方配置和生成任务链路完成，具备请求幂等、状态跟踪、计费快照、失败补偿与内容审核基础。
- 企业数据通过租户、组织和角色上下文隔离，重要管理操作记录审计信息。
