# 知启云AI V1.0 软件著作权说明书截图清单

## 截图通用要求

- 使用同一版本、同一品牌名称和同一套演示数据。
- 避免出现真实手机号、身份证号、银行卡号、密钥、企业证件或未脱敏用户数据。
- 截图应完整、清晰，保留页面标题、主要操作区和结果区；不得使用设计稿冒充运行页面。
- 移动端优先使用 1080×1920 竖屏截图；管理端建议使用 1920×1080 或更高分辨率。
- 文件名建议采用 `序号-模块-页面-终端.png`。

## 说明书插图位置建议

1. 登录、首页各放置 1 张整页截图。
2. AI 生图、视频、PPT 各放置“输入页”和“结果/任务页”两张截图。
3. 智能体和知识库分别放置“配置/列表”和“对话/检索结果”截图。
4. 作品、钱包、企业管理、模型管理、计费和权限各放置 1 张代表截图。
5. 功能说明书中的占位框在正式提交前替换为上述真实截图；替换后重新检查页码和目录。
