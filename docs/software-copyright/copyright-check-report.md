## 十、正式提交前建议顺序

1. 著作权人确认软件全称、V1.0、权属和开发完成日期。
2. 法务补全隐私政策、用户协议、SDK 清单、注销和投诉渠道。
3. 完成 APP 备案并取得备案号。
4. 采集/确认真实截图，替换 Word 占位并进行逐页视觉检查。
5. 冻结 V1.0 源码，确认是否按受理机构口径重导连续前后 30 页。
6. 申请软著并取得证书。
7. 使用正式长期签名证书生成 release APK，完成真机与隐私合规测试。
8. 准备审核账号后提交应用市场审核。
