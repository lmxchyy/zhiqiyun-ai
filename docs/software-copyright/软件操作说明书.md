# 知启云AI企业级AI创作与智能体平台 V1.0 软件操作说明书

## 1. 文档说明

本文档说明知启云AI用户端和企业管理端的主要操作流程。不同终端的布局可能略有差异，但账号、任务、作品和企业数据通过统一服务端接口保持一致。涉及付费、企业认证和第三方模型的功能，以实际开通权限和运营配置为准。

## 2. 运行与访问

### 2.1 用户端

用户端可构建为 Android/iOS App、H5 和微信小程序。启动后默认进入首页或登录页。游客可浏览公开能力；创建任务、保存作品、访问钱包、企业空间等受保护操作会要求登录。

### 2.2 企业管理端

管理端通过浏览器访问，由具备后台角色的账号登录。系统根据角色和菜单权限显示管理模块，不同岗位只能访问授权范围内的数据和操作。

## 3. 登录与注册

1. 打开应用，进入“知启云AI”登录页面。
2. 选择手机号验证码登录、账号密码登录或终端支持的微信快捷登录。
3. 阅读并勾选《用户协议》和《隐私政策》。
4. 验证成功后，系统创建或识别账号，并恢复登录前的目标页面或待执行操作。
5. 如暂不登录，可选择游客浏览；进行创作、保存或付费时再登录。

注意：正式上架前必须发布有效的用户协议和隐私政策正文，并验证账号注销入口。

## 4. 首页与创作入口

1. 首页展示创作入口、推荐能力、案例、套餐和最近作品。
2. 点击“创作”进入能力选择页。
3. 选择 AI 生图、视频生成、PPT 文档、智能体或知识库等功能。
4. 系统根据当前终端、账号套餐、企业权限和后台模型配置判断能力是否可用。

## 5. AI 智能对话

1. 进入智能体或知识问答页面。
2. 新建对话，或从历史对话中选择已有会话。
3. 在输入区提交问题或任务描述。
4. 系统将问题发送给已绑定的大语言模型；知识库智能体会先检索授权文档，再生成带引用的回答。
5. 查看回答、引用来源和运行状态；必要时继续追问。

## 6. AI 生图

1. 在创作中心选择“AI 生图”。
2. 输入图片主题、用途、风格、比例和质量要求。
3. 可从相册或相机添加参考图，参考图仅在用户主动选择后上传。
4. 确认模型和预计消耗后提交任务。
5. 在任务区域查看排队、生成中、成功或失败状态。
6. 成功后可预览、下载、收藏、移动项目或再次生成。

## 7. AI 视频

1. 选择“视频生成”。
2. 输入视频内容、镜头、比例、时长等信息，可按页面能力添加参考图片。
3. 提交后系统创建异步任务并显示进度。
4. 任务完成后进入作品详情预览或保存视频；失败时按页面提示重试。

## 8. PPT 文档生成

1. 选择“PPT 文档生成”。
2. 输入演示主题、受众、页数、风格和用途。
3. 生成并确认大纲，可编辑章节标题和内容重点。
4. 提交生成任务，等待系统生成页面文案和配图计划。
5. 在 PPT 编辑器中调整页面内容、主题和视觉素材。
6. 完成后导出 PPTX 或 PDF；导出能力以服务端配置为准。

## 9. AI 画布

AI 画布以创作编辑工作区形式集成在 PPT 页面编辑、视觉素材调整和海报绘制流程中。用户选择页面或元素后，可调整内容、替换配图、预览效果并保存。当前仓库未发现独立命名为“AI画布”的 App 路由，正式说明和截图应采用实际集成编辑页面，避免把规划功能表述为独立模块。

## 10. 智能体

1. 进入智能体中心，查看公开或企业授权的智能体。
2. 选择智能体并进入详情，阅读能力说明和适用范围。
3. 新建会话并提交任务。
4. 企业管理员可创建 AI 员工、配置知识库绑定、模型能力和成员权限。
5. 运行记录、输入输出和作品遵循用户与企业空间隔离规则。

## 11. 知识库

1. 管理端或企业空间创建知识库。
2. 上传授权文档，系统完成解析、切分、索引和状态记录。
3. 为知识智能体绑定一个或多个知识库。
4. 用户发起问题，系统检索相关片段并生成回答。
5. 用户可查看引用信息；管理员可管理文档、标签、分类和访问权限。

## 12. 作品中心

1. 进入“我的作品”查看图片、视频、PPT 等结果。
2. 使用类型、状态、关键词、收藏或项目筛选作品。
3. 打开详情后可下载、收藏、归档、恢复、删除或再次创作。
4. 文件下载或保存到相册时，系统在用户主动操作后申请相应权限。

## 13. 钱包、会员与订单

1. 在“我的”中进入钱包、会员或充值方案。
2. 查看余额、Token/算力、会员权益和消耗记录。
3. 选择由服务端返回的商品和价格，确认订单。
4. 在支持的终端调用对应支付渠道，并等待服务端确认支付结果。
5. 支付成功后，系统通过幂等权益发放流程更新会员或额度；用户可查看订单、退款和发票记录。

## 14. 企业管理中心

1. 进入企业中心，创建企业、申请加入或切换当前企业空间。
2. 企业管理员查看概览、成员、组织架构、角色、AI 员工、企业算力和使用明细。
3. 邀请成员或审核加入申请，并为成员配置角色与组织归属。
4. 需要认证时提交真实企业名称、统一社会信用代码和证明材料。
5. 在企业设置中管理 Connector、服务状态和审计日志。

## 15. 管理端操作

### 15.1 用户与租户

进入“客户与企业”，查询用户、企业、组织和认证信息。敏感标识在展示时应脱敏。涉及冻结、解绑或额度调整的操作应填写原因并保留审计记录。

### 15.2 模型与渠道

进入“AI 与内容”，维护能力模块、模型、参数 Schema、租户限制和上游 API 渠道。渠道密钥只通过安全配置保存，页面不应回显完整明文。

### 15.3 Token 计费

进入“商品与计费”，维护商品、价格、计费规则和成本；在账务模块查看钱包流水、任务扣费、对账和异常事件。历史任务使用生成时的计费快照，避免规则修改影响历史账目。

### 15.4 权限与内容审核

进入“系统管理”维护后台账号、角色、菜单和数据权限；进入合规或异常中心查看输入、输出、下载和分享环节的内容审核记录，并按权限执行复核。

### 15.5 Agent 与知识库

管理员可管理智能体资料、知识库、文档、绑定关系、会话运行和引用记录。企业管理员默认不能直接查看不属于其授权范围的个人提示词、原始文件或对话正文。

## 16. 常见异常处理

- 网络异常：保留已填写内容，重新加载或重新提交前确认是否已创建任务。
- 登录失效：刷新令牌失败后重新登录，登录完成后返回原页面。
- 生成失败：查看错误提示；可重试任务只创建一次业务操作，避免重复扣费。
- 支付结果未知：通过订单状态同步或服务端查单确认，不重复创建订单。
- 文件上传失败：检查文件格式、大小、网络和账号权限。
- 权限不足：切换正确企业空间或联系管理员授权。

## 17. 安全退出

用户可退出当前账号或退出全部设备。正式上架前应补充可验证的账号注销入口、处理时限与数据处置规则，并与隐私政策保持一致。
