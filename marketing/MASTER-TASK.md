# 总任务：知启云AI品牌宣传海报系统

## 目标

建立一套可长期维护、持续扩展的企业品牌宣传体系。任务不是临时生成若干图片，而是按编号、共享设计系统和发布规范逐张产出可追溯的品牌资产。

## 品牌定位

- 品牌名称：知启云AI
- 定位：企业AI生产力平台
- 副标题：企业级AI创作与智能体平台
- Slogan：让AI成为企业生产力

## 视觉方向

企业级 SaaS；参考 Apple、OpenAI、Notion、Linear、Arc Browser 的克制、留白和高级感；结合极简科技、玻璃拟态、3D 光效、蓝紫渐变与未来数字空间。不得照搬第三方品牌识别，不得使用电商风或廉价科技模板。

## 单张执行协议

1. 接收一个明确编号，例如 `Poster-001`。
2. 只读取该编号 Markdown 与共享设计系统，不联动生成其他编号。
3. 使用 `image2`，每次只发起一次单图生成。
4. 成图必须为 1080 × 1920 PNG，并使用指定品牌 Logo `marketing/assets/zhiqiyun-ai-logo-v2-transparent.png`。
5. 一张海报只表达一个主题，正文保持短促，不堆砌功能。
6. 上传公共存储后记录结果，立即停止。

## 硬性禁令

- 禁止一次生成多张或主动提供多版本。
- 禁止拼图、合集、网格、画中画和多 Banner 并排。
- 禁止重新绘制、改字或变形 Logo；深色背景中必须使用与海报同色系的浅蓝紫玻璃承托保证对比度。
- 禁止二维码、网址、邮箱和电话号码。
- 禁止把 80 个 Prompt 写入页面、后端路由或生成服务代码。
- 禁止绕过 `design-system/` 为单张任务重新定义品牌色、字体、CTA 或基础布局。
- 禁止把最终 PNG/视频提交进 Git；仓库只保存任务、规范与发布记录。

## 完成门槛

只有在单张 PNG 校验通过、公共存储上传成功、任务 Markdown 已记录 `file_id/object_key/public_url` 后，才可把该任务标为 `completed`。任何一步失败均保持 `pending` 或标记 `blocked`，且不得自动开始下一张。
